# ТехРемонт Pro - Сайт сервиса по ремонту техники

Современный, продающий сайт для сервиса по ремонту техники с интеграцией Telegram бота для уведомлений о новых заявках.

Функциональность

-  Современный дизайн с анимациями и hover-эффектами
-  Полностью адаптивная верстка для всех устройств
-  Разделы услуг по категориям техники
-  Форма обратной связи с валидацией
-  Интеграция с Telegram ботом для уведомлений
-  Сохранение заявок в базе данных Supabase

Настройка

1. Подключение к Supabase
2. Настройка Telegram бота
3. Запуск проекта

Структура проекта

src/
├── lib/
│   └── supabase.ts          # Конфигурация Supabase
├── App.tsx                  # Основной компонент
└── main.tsx                 # Точка входа

supabase/
├── functions/
│   └── send-telegram-notification/
│       └── index.ts         # Edge Function для Telegram
└── migrations/
    └── create_repair_requests.sql  # Миграция БД

Использование

1. Клиент заполняет форму на сайте
2. Заявка сохраняется в базе данных Supabase
3. Автоматически отправляется уведомление в Telegram
4. Мастер получает уведомление и связывается с клиентом

Технологии

- Frontend: React, TypeScript, Tailwind CSS
- Backend: Supabase (PostgreSQL + Edge Functions)
- Интеграция: Telegram Bot API
- Иконки: Lucide React
- Сборка: Vite

Безопасность

- Row Level Security (RLS) настроен для всех таблиц
- Валидация данных на клиенте и сервере
- Безопасное хранение токенов в переменных окружения
